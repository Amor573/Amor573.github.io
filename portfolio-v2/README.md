# Muhammed Akintola — Portfolio V2

The portfolio is a static single-page website with dynamic case studies and category filters. All content is in `index.html`. No dependencies or backend services are required.

## Deploy on Vercel

1. Import `Amor573/Amor573.github.io` from GitHub.
2. Set **Root Directory** to `portfolio-v2`.
3. Set Framework Preset to **Other**.
4. Leave Build Command empty and use `.` as Output Directory if Vercel asks for one.
5. Deploy and open `/?case=eks-cicd` to verify case-study navigation.

The legacy GitHub Pages homepage at repository root is unchanged. This directory is also compatible with GitHub Pages subdirectory hosting if GitHub Pages is active.

## Portfolio editorial policy
- Public code is linked only for existing repositories.
- Reference, private experience, ongoing labs and runbooks are labeled.
- Do not add screenshots with IP addresses, credentials, production customer data or session information.
- The site uses a professional contact link without exposing personal emails.
